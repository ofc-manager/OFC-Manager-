# OFC Manager

Aplicação web de gerenciamento de clube de futebol.

## 🎯 Funcionalidades

- **Home**: Visualizar informações do clube (dinheiro, ranking mundial)
- **Mercado**: Consultar jogadores disponíveis para transferência
- **Partidas**: Acompanhar partidas ao vivo

## 🏗️ Estrutura do Projeto

```
OFC-Manager/
├── index.html
├── css/
│   └── global.css
├── screens/
│   ├── home.js
│   ├── market.js
│   └── matches.js
├── js/
│   ├── app.js
│   └── navigation.js
└── README.md
```

## 🚀 Como Usar

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
3. Navegue pelas abas: Home, Mercado, Partidas

## 💻 Tecnologias

- HTML5
- CSS3
- JavaScript (ES6 Modules)
